01 · The mark

The Listening Drop.

A speech bubble compressed to a coin. The inner mark — a single dot with two concentric arcs — is a quiet pulse. It animates: 2.6s breath when the mic is live; expands outward when an expense saves.

Construction

Built on a 160-unit grid. The droplet uses a 4-point cubic spline; the tail occupies the lower-left quadrant at a 32° angle. Optical center sits 4 units above geometric center to compensate for the tail mass. The inner pulse is locked at radius 6, with arcs at radii 16 and 28 — never use a 4th ring.

08 · Rules of use

Do · Don't.

✓
Do
Use the cream variant as default. Sage as the primary brand-y option. Ink only on busy interfaces where a darker icon adds clarity.
×
Don't
Never use blue, teal, or any cyan. The whole brand position is built on not being fintech.
✓
Do
Animate the inner pulse only when it represents a real state — listening, saving, syncing. Idle = motionless.
×
Don't
Don't add a microphone glyph to the icon. Don't add a coin glyph either. The shape already says both.
✓
Do
Pair the wordmark with at least 12px of clearspace on every side, equal to the cap-height of "M".
×
Don't
Don't outline the wordmark, italicize it, or use sans for the brand name. New York 500 only.
✓
Do
Drop the inner pulse below 24px. Below 16px, solid silhouette only.
×
Don't
Don't apply gradients, drop shadows, or skeuomorphic effects to the mark. The shape is the design.
09 · Engineering handoff

Drop-in spec for Claude Code.

SVG path · droplet

M80 18 C 122 18, 142 50, 142 86 C 142 118, 116 142, 80 142 C 70 142, 60 140, 52 136 L 30 142 L 38 122 C 24 110, 18 96, 18 86 C 18 50, 38 18, 80 18 Z

ViewBox: 0 0 160 160. Fill currentColor.

Inner pulse

Center dot r=6, two arcs r=16, 28. Stroke widths 3.5, 3. Opacity 0.85, 0.45.

Bind to isListening state; animate transform-scale 1 ↔ 1.08 over 2.6s ease-in-out.

Color tokens

--murmur-ink: #1B1915
--murmur-cream: #FBFAF7
--murmur-sage: #3F5A3E

Type stack

--font-display: "New York", "Iowan Old Style", Georgia, serif
--font-text: -apple-system, "SF Pro Text", system-ui, sans-serif
--font-mono: "SF Mono", Menlo, monospace

App icon export

Generate at 1024×1024 from the cream variant. iOS will mask to its own corner radius — don't pre-round.

Tinted icon: solid silhouette only, no inner pulse.

Splash spec

Hold 800ms after first paint. Fade out 320ms on app-ready event. Tagline shows only on cold start (not on resume).

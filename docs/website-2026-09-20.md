# itsmurmur.com, redesigned around one decision (Sep 20, 2026)

The owner tried the site on his own Windows machine, could not find the
Windows download, and said the previous pass had added words rather than
taken ownership of the design. Both were fair. This is what changed and
why.

## What was wrong

| Problem | Evidence |
| --- | --- |
| Windows and Intel Mac were invisible | They existed only in an 11px grey line under the hero buttons and in the footer. A download nobody can find is a download that does not ship. |
| The offer was a paragraph | Free forever, the fortnight of Plus and "no bank linking" were prose in the middle of the hero, where sceptics skim. |
| Eight FAQ answers, all open | A wall of text, so nobody read any of it. |
| No product, only drawings | Every visual was hand-built CSS. The App Store showed the real app; the site did not. |
| No explanation of the loop | The page claimed things about voice capture but never walked through say it, filed, see it. |
| Links shared as bare URLs | No `og:image` at all, so iMessage, Slack, X and LinkedIn previewed nothing. |

## What the page does now

1. **Nav** carries the four destinations that matter (How it works,
   Features, Pricing, FAQ), keeps Log in reachable on phones, and ends in a
   green "Get Murmur" pill.
2. **Hero**: the download buttons are platform-aware
   (`src/components/HeroDownloads.tsx`). A Windows visitor sees "Windows
   app · Plus"; a Mac visitor sees Mac; everyone else is offered the web
   app; a tertiary "Mac, Windows & web" jumps to the download section.
   iPhone always leads, because the phone is where the product happens.
3. **The offer** is three checked lines, not a sentence: free forever,
   14 days of Plus with no card, no bank linking.
4. **How it works**: say it, Murmur files it, you see where it goes.
5. **The app itself**: the six shipped App Store screenshots in a snapping
   scroller, so the site and the listing say exactly the same thing.
6. **FAQ** is a `<details>` accordion. No JavaScript, still in the DOM for
   search engines and the FAQPage structured data, first answer open.
7. **Get Murmur** is a dark band with four real cards: iPhone (free
   forever), Mac (Apple Silicon and Intel, signed and notarized), Windows
   (with the honest unsigned-installer warning), Web. It replaced the old
   closing CTA, which said the same thing with fewer answers.
8. **Sticky bar on phones** keeps "Free forever · Get Murmur" in reach
   below 760px, where most of the traffic is.
9. **Share card**: `public/og.png`, the site's own hero at 1200x630, wired
   into both Open Graph and Twitter metadata.

## Rules kept

- No invented ratings, user counts or testimonials. There are none yet, so
  the page claims none.
- Every link resolves: all three desktop artifacts were checked 200 before
  shipping.
- Honest about the rough edge: the Windows installer is unsigned and the
  card says so instead of letting SmartScreen say it first.
- CSP unchanged: no external scripts, no external images, no fonts beyond
  the self-hosted ones.

## Regenerating the images

```bash
cd apps/web
node scripts/build-site-assets.mjs shots        # App Store screenshots -> public/shots/*.webp
npm run build && npx next start -p 3000
node scripts/build-site-assets.mjs og http://localhost:3000/   # hero -> public/og.png
```

`scripts/build-site-assets.mjs` drives headless Chrome over the DevTools
protocol on purpose: `--window-size` is clamped to the OS minimum window
width, which silently renders phone layouts at ~460px and crops the
screenshot, and that is exactly how a layout bug gets missed.

## Still open, in priority order

1. **Proof.** The page has no social proof because Murmur has no ratings
   yet. The moment the App Store listing has them, put the star rating and
   a review quote under the hero. A short, signed founder note ("built and
   supported by one person, my email is below") is the honest stand-in and
   needs the owner's voice, not mine.
2. **Nothing is measured.** No site analytics, so no idea which section
   sends people to the App Store. A first-party counter is possible within
   the privacy policy; a third-party tag is not.
3. **English only** while the app speaks four languages, and the CFA,
   naira and cedi markets read French and Portuguese.
4. **One page only.** Comparison and how-to pages are how competitors
   collect search traffic; Murmur has the App Store listing and this page.
